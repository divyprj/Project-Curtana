# Project-Curtana Branding

## Repository description

Professional Android recovery, flashing, diagnostics, and automation toolkit for Xiaomi Curtana/Miatoll devices.

## Visual identity

Project-Curtana should feel technical, precise, and calm. The visual system should resemble infrastructure tooling more than a ROM fan page.

Recommended direction:

- **Primary color**: graphite `#20242a`
- **Accent color**: recovery orange `#f05a28`
- **Support color**: diagnostic blue `#2563eb`
- **Background**: near-white `#f7f8fa`
- **Typography**: modern sans-serif for banners, monospace accent for command snippets.

## Logo concept

The logo should combine:

- A minimal shield outline for safety.
- A small Android recovery bolt or terminal prompt.
- A subtle `C` mark for Curtana.

It should avoid device renders, copyrighted Xiaomi marks, and ROM project marks. The project can mention Xiaomi, Redmi, OrangeFox, and TWRP descriptively, but it should not use their branding as its own identity.

## Banner concept

Banner composition:

```text
[ Project-Curtana ]
Android recovery and flashing infrastructure for Xiaomi Curtana

ADB | Fastboot | FastbootD | OrangeFox | Firmware | Diagnostics
```

Use a dark graphite background, thin orange accent line, and small terminal-style status blocks. Keep the banner readable at GitHub social preview sizes.
