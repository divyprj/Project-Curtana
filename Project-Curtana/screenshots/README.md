# Screenshots

Store sanitized workflow screenshots here for documentation and release notes.

Recommended captures:

- ADB authorized device output.
- Fastboot detection.
- FastbootD screen.
- OrangeFox main screen.
- Sideload success.
- Windows Device Manager driver state.

Before committing screenshots, remove:

- IMEI.
- Serial number.
- Phone number.
- Account email.
- Personal filenames.
- Notification content.
