# Changelog

All notable changes to Project-Curtana are documented here.

The project follows [Semantic Versioning](https://semver.org/) and uses Conventional Commits for release notes.

## 0.1.0 - 2026-05-25

### Added

- Initial GitHub-ready repository architecture.
- Windows batch scripts for ADB, Fastboot, recovery, troubleshooting, and partition backup workflows.
- Python automation foundation for detection, SHA256 verification, recovery image scanning, and diagnostics.
- PowerShell diagnostics module for Windows support workflows.
- Curtana/Miatoll device profile configuration.
- Full documentation set covering installation, drivers, Fastboot, FastbootD, recovery, custom ROMs, stock restore, troubleshooting, architecture, safety, contribution, FAQ, security, and roadmap.
- GitHub issue templates, pull request template, and validation workflow.

### Security

- Added flashing safety model, anti-brick guidance, rollback warnings, and responsible disclosure policy.
